什么是动爻 · 活人该怎么筮（大衍筮法全流程）
一、什么是动爻
每爻三变后剩余策数 ÷ 4，得四值：6 老阴（动）· 7 少阳（静）· 8 少阴（静）· 9 老阳（动）。
7、8 为静爻：本爻不变。6、9 为动爻：阴至极必反阳、阳至极必反阴，动爻在成卦后要变，变后之卦即「之卦」。卦象中动爻以橙色描边标出。
断法（朱熹《易学启蒙》通行）：六爻皆静 → 以本卦卦辞断；一爻动 → 以该动爻爻辞断；两爻动 → 以本卦两动爻中上爻之辞为主；三爻动 → 以本卦与之卦卦辞合断（本卦为贞、之卦为悔）；四爻动 → 以之卦两静爻中下爻之辞断；五爻动 → 以之卦静爻之辞断；六爻全动 → 乾用「用九」、坤用「用六」，余卦以之卦卦辞断。
二、活人一步步怎么筮
备 50 策（蓍草 / 竹签 / 围棋子皆可），「大衍之数五十，其用四十有九」——先取 49 策（1 策置旁象太极）。每爻三变，六爻共十八变。
一变（49 策起）：① 随意分两堆（象两仪）→ ② 从右堆取 1 策挂起（象三才）→ ③ 左堆 4 个 4 个数，数剩 1–4 记左余 → ④ 右堆（已去掉挂的 1 策）同样 4 个 4 个数，数剩 1–4 记右余 → ⑤ 归奇 = 挂 1 + 左余 + 右余（正常为 5 或 9）→ 剩余 = 49 − 归奇（40 或 44）。
二变（40 或 44 策起）：同法再分二、挂一、揲四、归奇（正常归奇 4 或 8）→ 剩 32 / 36 / 40。
三变（32 / 36 / 40 策起）：再同法（正常归奇 4 或 8）→ 剩 24 / 28 / 32 / 36 → ÷ 4 = 6 / 7 / 8 / 9，得初爻。
换一卦再起 49 策，同法再筮五遍，得二爻至上爻，六爻成卦 → 按上文断法断之。
三、辅助计算怎么用
切到「活人辅助」模式：真人照上面步骤做分二、挂一、揲四（体力活），把 左堆余数 与 右堆余数 填进输入框，点「记录本变」，程序自动算归奇、剩余策数、爻值；三变定一爻，六爻成卦自动出卦象与断辞。若归奇非正常值（一变 5/9、二三变 4/8）会提示检查，但按诚实记录继续。

积年 = 上元甲子至所求年算数（锚点：万历戊子 1588 年积 10155505 算）。先以周纪 360 去之，余以 72 约之不尽为入元局数：局 = 积年 mod 72（余 0 取 72）；元 =（积年 mod 360）÷72 得甲子/丙子/戊子/庚子/壬子五元。月计起算加天正地正二算（积年+2）；时计不加二算、冬至后用阳局、夏至后用阴局。
日局（纪法求日，已实现）：基准弘治元年戊申（1488）正月初一（公历 01-14，日干支丙申）"截算得祖数 213 策"（213 mod 60 = 33 = 丙申，与历表互证自洽）。目标日祖数 = 213 + 距基准日天数（公历积日，逐日一进，闰日自然计入，等价"逐年一进一退、逢闰重退"）；局 = 祖数 mod 72，元与岁计同。
